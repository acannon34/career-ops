# Career Strategy

The strategic layer of `career-ops`. Where `career-ops/` runs the *operational* job-search
pipeline (scan, evaluate, tailor, apply), this folder holds the deliberate (3–9 month)
transition strategy out of the Accenture MD practice-leadership role toward two destinations:

- **PE / portfolio operating roles** — join a structure (operating partner, portfolio-company exec). **← current lead track**
- **Build / independent** — leave all structure (solo advisory, small firm, or productized IP)

The two tracks share a foundation (covenant review, narrative, build-in-public) and diverge around month 4.

**Relationship to the rest of career-ops:** verified proof points, archetype mapping, and comp
targets live in [`../modes/_profile.md`](../modes/_profile.md). This strategy layer *reuses* that
narrative and re-frames it for PE/operating buyers — it does not duplicate it. Lives in the
user-data layer; never auto-updated.

## Workflow

1. Drop raw source material (work history, reviews, deal sheets, brag docs) into `00-inbox/` from whatever machine has it.
2. We consolidate inbox material into the structured docs in `02-narrative/`.
3. Each track folder holds its own plan, targets, and artifacts.
4. `06-decision/` is where the PE-vs-independent fork gets resolved with real criteria.

## Structure

| Folder | Purpose |
|---|---|
| `00-inbox/` | Raw, unprocessed source material. Dump here, clean up later. |
| `01-foundation/` | Covenant review, comp/equity math, the "know your number" work. Gates everything. |
| `02-narrative/` | The dual-purpose narrative + LinkedIn/bio rewrite. The spine. |
| `03-track-pe/` | PE/operating-partner track: target firms, search contacts, pipeline. |
| `04-track-independent/` | Independent track: model choice, economics, anchor clients. |
| `05-outreach/` | Conversation tracker, message templates, meeting notes. |
| `06-decision/` | The fork: criteria, decision tree, go/no-go. |

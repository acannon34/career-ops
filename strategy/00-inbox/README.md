# 00 — Inbox

Dump raw source material here from any machine. Don't organize it perfectly — just get it in. We'll consolidate it into `02-narrative/` together.

## What to drop here

Anything that documents **what you built, what outcomes you drove, and your specific strengths.** Especially:

- **Brag docs / accomplishment lists** — anything you've already written
- **Performance reviews & promotion docs** — others' language about your impact is gold
- **Deal / project sheets** — wins, P&L numbers, growth %, named (or anonymized) clients
- **Practice metrics** — revenue you owned, team size, growth trajectory, margin
- **Recognition** — awards, internal recognition, client testimonials
- **Speaking / writing** — talks, posts, POVs you've authored
- **Skills inventories** — anything that names your specific strengths

## How to drop it

One file per source is fine. Suggested naming so it's traceable later:

```
source_<topic>_<yyyy-mm>.md      e.g. source_practice-pnl_2025-q4.md
review_<period>.md               e.g. review_fy25-annual.md
deal_<client-or-codename>.md     e.g. deal_acme-transformation.md
```

Plain text / markdown is easiest to work with, but drop PDFs or docs if that's what you have — we can extract.

## The one rule

**Quantify ruthlessly.** For every accomplishment, capture: the number (revenue, %, headcount, $ saved/influenced), the scope (yours vs. team's vs. firm's), and the outcome (what changed). "Owned the number" beats "led the engagement" every time for both destinations.

## Keep out

- Client-confidential deliverables or anything Accenture owns
- Anything under NDA
- Use *your* outcomes and framing, anonymize where needed
